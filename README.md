# Hotel Reservation System

This is a Java-based Hotel Reservation System developed as a desktop application using Java Swing. The project was created to practice Object-Oriented Programming concepts and understand how real-world hotel booking systems work.

The application allows users to view available rooms, search by category, complete bookings, simulate payments, generate bills, and manage reservations through a graphical interface.

---

## Project Overview

This project was built to simulate a hotel booking environment where users can:

- View available rooms
- Search rooms by category
- Book rooms
- Make simulated payments
- Generate booking bills
- Cancel reservations
- Track room availability

The system automatically assigns available rooms after successful booking.

---

## Features

- Desktop GUI using Java Swing
- Dark themed interface
- Room availability management
- Automatic room allocation
- Payment simulation
- UPI payment option
- Debit/Credit card option
- Cash payment option
- OTP verification
- Payment processing animation
- Booking confirmation
- Transaction bill generation
- Export bill as PDF
- Booking cancellation
- File storage support
